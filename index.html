Overview

Gaussian blur is widely used for privacy protection in photos shared online, yet it often fails to anonymize faces. Revelio is an identity-aware face deblurring system that leverages conditional diffusion and identity retrieval to reconstruct blurred faces while preserving the original identity. This page is the official website of the Revelio project; full results, figures, and dataset links will be added here after publication.

Access to Code

Because the method can potentially enable misuse (e.g., deanonymization), the code is not publicly released. Researchers may request access for legitimate academic purposes by emailing the authors. Please include:

  1. Your name and institutional affiliation
  2. Intended research use and a brief justification
  3. A statement confirming responsible, ethical use (no privacy violations)
